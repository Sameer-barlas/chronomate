# ChronoMate Chess Clock

Zero-latency offline over-the-board chess timer with Norman-principled one-tap presets, asymmetric custom controls, and drift-free millisecond precision.

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```

5. Run automated tests:
   ```bash
   npm test
   ```
